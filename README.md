# AI 产品从想法到上线 · 开箱工具包

> 给**不懂代码的产品经理 / 学生**的一键启动包：把本文件夹交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 带你从"一个想法"走到"上线产品"，全程不需要你写代码。

## 这能干什么

你只需要一个产品想法（有 PRD 更好，没有也行）。AI 负责所有技术工作：写代码、跑测试、做界面、部署上线；你只做少量"必须本人才能做"的事（注册云账号、填密钥、验收）。

## 怎么开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（收到压缩包就先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版只能聊天的 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"，看不懂就说"用产品语言再说一遍"。

> 完整操作手册见 [开始看这里.md](./开始看这里.md)。

## 6 个阶段

| 阶段 | 内容 | 你做什么 |
| --- | --- | --- |
| 0 | PRD 体检 | 回答问题（每次不超过 5 个，可回复"按推荐"） |
| 1 | 技术适配 | 确认 AI 理解对不对、有没有多出你没要求的费用/范围 |
| 2 | 后端 MVP | 提供模型 Key、对真实生成结果打分、照清单验收 |
| 3 | 正式前端 | 给视觉方向、看代表页反馈、真机走一遍 |
| 4 | 上线 | 注册/认证云账号、控制台照着点、按验收清单验证 |
| 5 | 收尾 | 按提示删除云密钥 |

阶段 2、3 内部会分多个子阶段，每轮都是"AI 做、你验收"。每个阶段结束 AI 必须交**证据包**（截图 + 可打开的地址/照着点步骤 + 是否表），你可以自己核对。

## 环境要求

- 一个编码 AI 工具（Claude Code / Cursor / Codex CLI 等）
- Python 3.12、Node.js 22、Git（开发时会检查，缺了 AI 会给"照着装"步骤）
- 一个模型 API Key（开发期可先不买，AI 用模拟数据推进；验收前必须补齐）

## 文件夹结构

```text
项目根目录/
├── README.md                    ← 本文件（GitHub 首页）
├── 开始看这里.md                 ← 产品经理操作手册（详细版）
├── AGENTS.md                    ← AI 规则卡（每次会话自动生效）
├── CLAUDE.md                    ← 引用 AGENTS.md（Claude Code 用）
├── .gitignore                   ← 防密钥泄露配置
└── docs/
    ├── PRD/
    │   └── PRD模板.md           ← 产品经理填的 8 字段模板
    ├── 手册/                    ← 三份给 AI 读的技术手册
    │   ├── AI产品Vibe Coding通用技术栈手册.md
    │   ├── AI产品Vibe Coding通用前端技术栈手册.md
    │   └── AI产品 Vibe Coding 通用上线部署手册.md
    ├── 项目状态.md              ← AI 自动创建（进度 + 决策台账）
    ├── 阶段文档/                ← AI 自动创建（技术适配声明、阶段开发文档）
    └── evidence/                ← AI 自动创建（每阶段证据包）
```

> `docs/项目状态.md`、`docs/阶段文档/`、`docs/evidence/` 由 AI 在开发过程中自动创建维护，产品经理可随时查看。
